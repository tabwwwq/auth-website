# Auth Website - Простая система авторизации

Простой веб-сайт с системой авторизации на PHP и MySQL. Проект демонстрирует базовые принципы аутентификации, безопасного хранения паролей и работы с базой данных.

## Описание проекта

Это учебный проект, который реализует полноценную систему регистрации и авторизации пользователей. После входа в систему пользователь может просмотреть список всех зарегистрированных пользователей.

## Основные возможности

- ✅ Регистрация новых пользователей
- ✅ Авторизация (вход в систему)
- ✅ Просмотр списка всех пользователей
- ✅ Выход из системы
- ✅ Безопасное хранение паролей (хеширование)
- ✅ Защита от SQL-инъекций (prepared statements)
- ✅ Валидация данных на стороне сервера
- ✅ Адаптивный дизайн

## Требования

Для работы проекта необходимо:

- **PHP** 7.0 или выше
- **MySQL** 5.7 или выше / **MariaDB** 10.2 или выше
- **Веб-сервер** (Apache, Nginx) или встроенный сервер PHP
- **Расширение PHP**: PDO, PDO_MySQL

## Инструкция по установке

### Шаг 1: Клонирование репозитория

```bash
git clone https://github.com/tabwwwq/auth-website.git
cd auth-website
```

### Шаг 2: Создание базы данных

1. Откройте phpMyAdmin или используйте командную строку MySQL
2. Создайте новую базу данных:

```sql
CREATE DATABASE auth_website;
```

3. Импортируйте SQL скрипт:

**Через phpMyAdmin:**
- Выберите базу данных `auth_website`
- Перейдите на вкладку "Импорт"
- Выберите файл `database.sql`
- Нажмите "Вперёд"

**Через командную строку:**

```bash
mysql -u root -p auth_website < database.sql
```

### Шаг 3: Настройка подключения к базе данных

Откройте файл `config.php` и при необходимости измените параметры подключения:

```php
$host = 'localhost';      // Хост базы данных
$dbname = 'auth_website'; // Имя базы данных
$username = 'root';       // Имя пользователя MySQL
$password = '';           // Пароль пользователя MySQL
```

### Шаг 4: Запуск проекта

**Вариант 1: Использование встроенного сервера PHP (для разработки)**

```bash
php -S localhost:8000
```

Откройте браузер и перейдите по адресу: `http://localhost:8000`

**Вариант 2: Использование Apache/Nginx**

1. Скопируйте файлы проекта в директорию веб-сервера:
   - Apache (XAMPP/WAMP): `htdocs/auth-website/`
   - Apache (Linux): `/var/www/html/auth-website/`
   - Nginx: настройте корневую директорию на папку проекта

2. Откройте браузер и перейдите по адресу:
   - `http://localhost/auth-website/` (Apache)
   - или настроенный адрес для Nginx

## Использование

### Регистрация нового пользователя

1. Откройте страницу `register.php`
2. Заполните форму:
   - Имя пользователя (от 3 до 50 символов)
   - Email (корректный адрес электронной почты)
   - Пароль (минимум 6 символов)
   - Подтверждение пароля
3. Нажмите "Зарегистрироваться"
4. После успешной регистрации вы будете перенаправлены на страницу входа

### Вход в систему

1. Откройте страницу `login.php`
2. Введите имя пользователя и пароль
3. Нажмите "Войти"
4. После успешного входа вы будете перенаправлены на главную страницу

### Просмотр списка пользователей

После успешного входа на главной странице (`index.php`) отображается:
- Приветствие с вашим именем пользователя
- Таблица со всеми зарегистрированными пользователями:
  - ID пользователя
  - Имя пользователя
  - Email
  - Дата регистрации
- Общее количество пользователей
- Кнопка "Выйти"

### Выход из системы

Нажмите кнопку "Выйти" на главной странице или перейдите напрямую на `logout.php`

## Используемые технологии

- **Backend**: PHP (нативный, без фреймворков)
- **База данных**: MySQL
- **Frontend**: HTML5, CSS3
- **Безопасность**: 
  - PDO Prepared Statements (защита от SQL-инъекций)
  - password_hash() и password_verify() (безопасное хеширование паролей)
  - htmlspecialchars() (защита от XSS-атак)
  - PHP Sessions (управление сессиями)

## Безопасность

Проект реализует следующие меры безопасности:

1. **Хеширование паролей**: Использование `password_hash()` с алгоритмом bcrypt
2. **Prepared Statements**: Защита от SQL-инъекций через PDO
3. **Валидация данных**: Проверка всех входных данных на сервере
4. **Экранирование вывода**: Использование `htmlspecialchars()` для защиты от XSS
5. **Проверка сессий**: Защита страниц от несанкционированного доступа
6. **HTTPS**: Рекомендуется для production (не требуется для локальной разработки)

## Устранение проблем

### Ошибка подключения к базе данных

**Проблема**: "Ошибка подключения к базе данных"

**Решение**:
1. Убедитесь, что MySQL запущен
2. Проверьте правильность данных в `config.php`
3. Убедитесь, что база данных `auth_website` создана
4. Проверьте права доступа пользователя MySQL

### Ошибка "Class 'PDO' not found"

**Проблема**: PHP не может найти класс PDO

**Решение**:
1. Убедитесь, что расширение PDO включено в `php.ini`:
   ```ini
   extension=pdo_mysql
   ```
2. Перезапустите веб-сервер

### Страница не загружается или отображается код PHP

**Проблема**: Браузер показывает исходный код PHP вместо выполнения скрипта

**Решение**:
1. Убедитесь, что вы используете веб-сервер (PHP встроенный, Apache, Nginx)
2. Не открывайте файлы напрямую через `file://`
3. Убедитесь, что PHP установлен и настроен правильно
